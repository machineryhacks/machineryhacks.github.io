# Nova — Sample HTML Website

A polished, responsive static website starter built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive visual design
- `script.js` — simple interactions
- `README.md` — project notes

## How to use
1. Extract the ZIP.
2. Open `index.html` in any modern browser.
3. Edit the text, colors, and sections in the files to customize it.

No server, framework, package manager, or internet connection is required.
