# Machineryhacks Static Website

This folder is a static export generated from the supplied Ghost JSON export.

## Deploy
Upload the contents of this folder to GitHub Pages (or Netlify/Vercel). No server or database is required.

## Structure
- index.html — homepage
- about.html — About page
- posts/ — individual article pages
- assets/style.css — responsive styling

External feature-image URLs from the Ghost export are retained.
